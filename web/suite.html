Generalization protocols

Pair-safe
Warm start

Unseen drug–protein combinations. Both entities are present in training.

Cold drug

Test compounds never occur in the training interactions.

Cold target

Test protein sequences are never used during training.

Cold drug–target

Both entity types are held out, with mixed cross-block observations excluded.

A single-target enzyme CSV cannot be used to claim cold-target or cold-both performance. Highly homologous proteins also require additional sequence-similarity controls.

EXTENSIBILITY / RESEARCH CODE

Custom Python models

Upload a Python module or Jupyter notebook defining your estimator. The server stores code but does not execute it unless a dedicated isolated Docker runtime is available.

Model interface

.py / .ipynb

Define build_model(task, params) returning an estimator supporting fit, predict, and optionally predict_proba. Notebook code cells must be standard Python without shell magics.

from sklearn.ensemble import RandomForestClassifier, RandomForestRegressor

def build_model(task, params):
    seed = params.get("random_state", 42)
    if task == "classification":
        return RandomForestClassifier(n_estimators=80, random_state=seed)
    return RandomForestRegressor(n_estimators=80, random_state=seed)

Isolated training

Checking runtime…
Python model files can execute arbitrary code. Run custom models only on a trusted local installation. Docker isolation reduces exposure but does not guarantee absolute containment; never enable this on a public multi-user server without additional security review.

Setup on Windows

Install Docker Desktop with Linux containers enabled, then run BUILD_CUSTOM_SANDBOX.bat in the application folder. Rebuild after installing new supported dependencies.

Inspect protein structures from the RCSB PDB, build illustrative ligand conformers, and run an optional rigid-receptor Vina calculation using appropriately prepared structures.

3D renderer
Enter a PDB ID or a SMILES structure, then load the 3D model. The viewer requires access to the 3Dmol library.

Structures downloaded from PDB are for inspection. A raw PDB file is not necessarily an appropriate docking receptor without scientific preparation.

Checking engine…
